# obs-slideshow-preview

The OBS plugin that adds image slideshow with dock showing preview next slide.
画像スライドショーを追加し、次のスライドのプレビューをドックに表示するOBSプラグイン。

## Installation (インストール方法)

Follow bellow instructions. Plugin files available in [Releases](https://github.com/Keinsleif/obs-slideshow-preview/releases)
下記のリンク先のガイドにしたがってインストールしてください。プラグインファイルは [リリース](https://github.com/Keinsleif/obs-slideshow-preview/releases) から入手可能です。

<https://obsproject.com/kb/plugins-guide>

> In v0.0.1, Linux only supports OBS v32.
> Windows and macOS supports only OBS v33 or above.
>
> v0.0.1では、Linux版はOBS v32のみをサポートします。
> WindowsとmacOSではOBS v33のみをサポートします。
